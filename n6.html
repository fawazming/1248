Question 4 | Search in Artificial Intelligence

i) What a search problem is

A search problem is a formal representation of a problem in which an agent must find a sequence of actions that leads from a given initial state to a goal state within a state space. Formally, it is the process of exploring possible states and transitions, using a search algorithm, to determine a path (solution) that satisfies the goal - ideally at minimum cost.

In other words, given an initial situation, a set of allowed moves and a definition of success, search explores alternatives and returns the action sequence that reaches the goal. Search is fundamental to game playing, route planning, puzzle solving and problem-solving agents.

ii) Five components of a search problem

#ComponentDescription
1Initial stateThe state in which the agent starts the search.
2Actions / Operators (successor function)The set of possible moves available in a given state; applying an action produces a new state.
3State space / Transition modelThe set of all states reachable from the initial state, and a description of the result of each action (how states connect).
4Goal testA test that determines whether a given state is a goal state.
5Path costA numeric cost assigned to a path; the sum of the step costs of the actions along the path. Used to find the least-cost (optimal) solution.

Memory Aid: I-A-S-G-P: Initial state, Actions, State space, Goal test, Path cost.

iii) Requisite steps for a search process

Formulate problem -> Represent state space -> Choose strategy -> Expand and test -> Extract solution (goal test applied at each expansion; loop until goal found or frontier empty).

  1. Formulate the problem: define the initial state, actions, transition model, goal test and path-cost function.
  2. Represent the state space: build the graph/tree of states and transitions.
  3. Choose a search strategy: select an algorithm - uninformed (BFS, DFS, uniform-cost) or informed/heuristic (greedy best-first, A*).
  4. Initialise the frontier (open list) with the initial state.
  5. Loop: remove/select a node from the frontier; apply the goal test; if not a goal, expand it using the successor function and add the resulting nodes to the frontier (tracking visited states to avoid repeats).
  6. Repeat until a goal state is reached or the frontier is empty (no solution).
  7. Extract the solution by tracing back the path from the goal to the initial state, and report/measure its cost and optimality.

Key Idea: Search = formulate -> represent -> choose strategy -> expand and test -> extract path. Good strategies keep search complete, optimal and efficient.
