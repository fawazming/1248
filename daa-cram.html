Formulas

  • 1+2+..+n = n(n+1)/2. 1+2+..+(n-1)=n(n-1)/2.
  • Cavg(seq search)=p(n+1)/2+(1-p)n.
  • Master: T(n)=aT(n/b)+f(n); n^(log_b a).

Complexity table

  • Sequential O(n); binary O(log n).
  • Bubble O(n^2) (best n); selection O(n^2) always; insertion O(n^2) (best n).
  • Merge O(n log n); quick O(n log n)/worst O(n^2); heap O(n log n).
  • Counting O(n+k); radix O(d(n+k)).

Recurrence table

  • T(n)=T(n-1)+1 -> n.
  • T(n)=2T(n-1)+1 -> 2^n-1 (Hanoi).
  • T(n)=T(n/2)+1 -> log n.
  • T(n)=2T(n/2)+n -> n log n.
  • T(n)=8T(n/2)+n^3 -> n^3.
  • T(n)=2T(n/2)+n^2 -> n^2.
  • T(n)=T(n-1)+n -> n^2.
