Question 1 | Fuzzy Logic and Knowledge Engineering

Scenario: A digital computer is excellent at discrete (crisp) data - values that are exactly true or false, 0 or 1. But many real-life situations are imprecise, vague, continuous and subjective, and do not conform to discrete descriptions.

a) How is this managed in AI?

AI manages it mainly through Fuzzy Logic (introduced by Lotfi Zadeh, 1965) and the wider family of soft-computing / approximate-reasoning techniques (fuzzy logic, neural networks, probabilistic / statistical reasoning and genetic algorithms).

Instead of forcing data into only TRUE (1) or FALSE (0), fuzzy logic lets a statement be partly true - any value in the range [0, 1]. It uses:

  • Linguistic variables - words such as "cold", "warm", "hot" or "tall", "short".
  • Membership functions - curves that state how much a value belongs to a fuzzy set (e.g. 0.7 hot).
  • Fuzzy IF-THEN rules - "IF temperature is hot THEN fan speed is high", evaluated with partial degrees of truth.

This allows machines to reason about imprecise, human-like concepts and to produce smoother, more robust decisions - mimicking how people reason with vague information.

Key Idea: Discrete data fits classical (Boolean) logic. Continuous, vague real-world data is handled by fuzzy logic, which maps crisp inputs to degrees of membership between 0 and 1.

b) Four principal stages of a fuzzy logic system

Crisp input -> Fuzzification -> Inference -> Aggregation -> Defuzzification -> Crisp output (Knowledge base = rules + membership functions)

#StageDescription
1FuzzificationCrisp (real-valued) inputs are converted into fuzzy linguistic values using membership functions. Each input gets a degree of membership in one or more fuzzy sets.
2Inference / Rule EvaluationA fuzzy rule base of IF-THEN rules is applied to the fuzzified inputs. Each triggered rule produces a fuzzy output whose strength equals the degree its condition is satisfied.
3Aggregation / CompositionThe fuzzy outputs of all triggered rules are combined into a single fuzzy output set (commonly with max/min operators).
4DefuzzificationThe aggregated fuzzy output set is converted back into one crisp value using a method such as the centroid (centre of gravity) or weighted average.

Memory Aid: F -> I -> A -> D (Fuzzify, Infer, Aggregate, Defuzzify). Think: "Feed In A Decision".

c) Two ways fuzzy logic contributed to AI

Contribution 1 - Fuzzy control systems (automation of imprecise real-world control). Fuzzy logic made it possible to build controllers that work like a human operator without an exact mathematical model of the process. It is used in washing machines (dirt/load sensing), air conditioners, cameras (auto-focus), ABS brakes, and even metro-train and lift control. This moved AI from the laboratory into everyday products and proved that "soft" reasoning can be reliable.

Contribution 2 - Reasoning under uncertainty and hybrid (soft-computing) AI. Fuzzy logic extended expert systems and decision-support tools so they can handle vague, linguistic knowledge ("if the patient looks very pale..."). It also became a foundation of soft computing: combined with neural networks it forms neuro-fuzzy systems (e.g. ANFIS) and with genetic algorithms it forms adaptive fuzzy systems. These hybrids are used in intelligent control, decision-making, pattern recognition and medical/industrial diagnosis.

Exam Tip: Name a concrete product/domain for each contribution (washing machine, camera, subway control for contribution 1; neuro-fuzzy/ANFIS for contribution 2) to score full marks.
