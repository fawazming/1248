Question 2 (cont.) | Genetic Programming and Turing

d) Step-by-step genetic programming process for the best BOT

Evolution cycle: Initialise (40 BOTs) -> Evaluate fitness (accuracy) -> Terminate if above 90%? -> Selection -> Crossover -> Mutation (+ reproduction) -> next generation (loop). If fitness above 90% -> BEST BOT emerges.

  1. Initialisation: randomly generate an initial population of 40 BOT programs (trees) from the chosen function set and terminal set.
  2. Fitness evaluation: test every BOT on the homonym dataset and score it as the percentage of words correctly vocalised (the fitness).
  3. Termination check: if the best BOT exceeds 90% accuracy (or the generation limit is reached), stop and output the best BOT.
  4. Selection: choose parent BOTs in proportion to fitness (roulette-wheel or tournament selection) so better BOTs reproduce more.
  5. Crossover (recombination): exchange randomly chosen sub-trees between two parents to create new offspring BOTs.
  6. Mutation: randomly alter a node or sub-tree in an offspring to preserve diversity and explore new solutions.
  7. Reproduction / elitism: copy the very best BOT unchanged into the next generation.
  8. Form the new generation from offspring + elites and return to step 2; repeat until a BOT reaches above 90% success.

e) What obtains at each step

StepWhat obtains / happens
1. InitialisationA diverse, random "generation 0" of 40 candidate BOT programs exists; no BOT is yet good or bad, but variety guarantees a search space.
2. Fitness evaluationEvery BOT is run against the labelled homonym set; each receives a numeric fitness = % correct. This converts performance into a comparable score.
3. Termination checkA decision is made: if any BOT exceeds 90% the search ends successfully; otherwise the loop continues. Prevents infinite running.
4. SelectionFitter BOTs are more likely to be picked as parents; weaker ones tend to disappear. This is "survival of the fittest" pressure.
5. CrossoverTwo parent programs swap sub-trees, producing offspring that combine useful "genetic material" from both successful BOTs.
6. MutationRandom small changes are introduced, injecting new genetic material and preventing the population from getting stuck in a local optimum.
7. Reproduction / elitismThe single best BOT is carried over unchanged, guaranteeing the best-so-far performance is never lost.
8. New generationA fresh population of 40 (mostly offspring, some elites) replaces the old one, and the cycle repeats until the above-90% target is met.

f) Turing's proposal on AI (1950)

The Imitation Game: Human (Respondent A) and Machine/AI (Respondent B) both give typed answers to an INTERROGATOR (Judge) who communicates only by text / teletype.

Background. In 1950 the English mathematician Alan Turing published the landmark paper "Computing Machinery and Intelligence", which opened with the question "Can machines think?". Because "thinking" is hard to define, he replaced it with an operational test - the Imitation Game, now called the Turing Test.

How the test works. An interrogator (judge) communicates by text (originally via teletype) with two hidden respondents: a human and a machine. The interrogator does not see or hear them and can ask any questions. If the judge cannot reliably tell which respondent is the machine and which is the human after a series of exchanges, then the machine is said to have passed the test and to exhibit intelligent behaviour.

Turing's key proposal / prediction. Turing argued that a machine that produces responses indistinguishable from a human's should be regarded as intelligent - intelligence can be judged by behaviour rather than by internal mechanism or consciousness. He predicted that by about the year 2000 a computer could fool an average interrogator a good proportion of the time.

Required capabilities. To pass, a machine needs natural-language processing, knowledge representation, automated reasoning, machine learning and (for the extended test) computer vision and speech - the classic pillars of AI.

Practical realisation. The test is implemented in the annual Loebner Prize competition (launched 1990). Only bronze medals have been awarded so far; the silver and gold prizes remain unclaimed - showing genuine human-level conversation is still an open AI challenge.

Criticism (bonus marks). The Chinese Room (Searle) argues the test measures simulation of understanding, not real understanding; others note it ignores embodiment, emotions and consciousness.
