CSC 715 Cheat Sheet

Intro & process

  • SE = engineering of all aspects of software production (not just coding).
  • Good software: maintainability, dependability/security, efficiency, acceptability.
  • Generic (developer controls spec) vs bespoke (customer controls spec).
  • Process activities: specification, design/implementation, validation, evolution.
  • Models: waterfall (stable requirements); incremental (change); reuse-oriented (components exist).

Agile & requirements

  • Agile values: individuals, working software, collaboration, responding to change.
  • XP: user stories, CI, TDD, pair programming, refactoring.
  • Scrum: Product Owner, Scrum Master, team; sprint planning/daily/review/retrospective.
  • User req (high level) vs system req (detailed); functional vs non-functional.
  • Elicitation: interviews, scenarios, use cases, ethnography.
  • Validation: reviews, prototyping, test-case generation.

Modeling & architecture

  • UML views: external (use case), interaction (sequence), structural (class), behavioral (state).
  • 4+1: logical, process, development, physical, +scenarios.
  • Patterns: MVC, layered. Pattern elements: name, problem, solution, consequences.
  • NFRs drive architecture (performance, security, safety, availability, maintainability).

Testing & evolution

  • Validation ("right product") vs defect ("product right").
  • Stages: unit, component, system; then alpha, beta, acceptance.
  • TDD: test first, then implement, then refactor.
  • Maintenance: fault repair, environmental adaptation, functionality addition.
  • Lehman: change, complexity, growth, quality. Legacy: scrap, leave, reengineer, replace.
