CSC 715 Cram Sheet - last hour

Must-know definitions

  • Software engineering; maintainability, dependability, efficiency, acceptability.
  • Generic vs bespoke; functional vs non-functional.
  • Waterfall, incremental, reuse; RUP phases (Inception, Elaboration, Construction, Transition).
  • Agile values; XP practices; Scrum roles/artifacts.
  • Requirements traceability; validation vs defect testing; TDD.

Key contrasts

  • Plan-driven (docs, sequential) vs agile (iterative, change expected).
  • User requirements (abstract) vs system requirements (detailed).
  • Validation ("right product") vs defect testing ("product right").
  • Alpha (developer site) vs beta (user site) vs acceptance (contractual).
  • Reengineering (improve maintainability) vs replacement.

Lists to recall

  • Four attributes of good software.
  • Four process activities.
  • Four elicitation techniques.
  • UML perspectives (external, interaction, structural, behavioral).
  • 4+1 views.
  • Three maintenance types.
  • Four legacy options (scrap, leave, reengineer, replace).

Exam pattern

For each answer: define -> give the model/example -> compare where asked -> state the trade-off. Name the keywords (convoy, aging, priority inversion are OS; here: convoy not relevant). Use Sommerville's terms (change avoidance/tolerance, locality of reference).
