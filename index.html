MSc Exam Companion

Lightweight phone edition: cheat sheets, cram sheets and coded model answers for four MSc modules, plus a study chatbot. Plain HTML only - no CSS, no JavaScript, so it loads fast on a basic 2G phone.

Read a Cheat page to learn the topic, a Cram page in the last hour before the exam, and an Answers page to memorise full model answers. Every question on an Answers page has a short code (for example DAA-Q14) you can jump straight to.

The four modules

  • DAA - Design & Analysis of Algorithms
  • CSC 711 - Advanced Operating Systems
  • CSC 715 - Software Engineering
  • CSC 718 - Internet Systems

1. Cheat sheets (learn)

  • DAA Cheat Sheet - algorithms, complexity, notation, recurrences, sorting, DP
  • CSC 711 Cheat Sheet - memory, file systems, I/O, OS structure, deadlock, scheduling
  • CSC 715 Cheat Sheet - process models, agile, requirements, design, testing, evolution
  • CSC 718 Cheat Sheet - end-to-end, routing, congestion, SDN, edge, IoT, blockchain

2. Cram sheets (last hour)

  • DAA Cram Sheet - formulas, complexity table, recurrence table
  • CSC 711 Cram Sheet - numbers, mnemonics, one-line contrasts
  • CSC 715 Cram Sheet - definitions and the key contrasts
  • CSC 718 Cram Sheet - formulas, ports, one-line summaries

3. Answer pages (coded model answers)

  • DAA Answers (DAA-Q1 ... DAA-Q63, plus 2-mark and 16-mark banks)
  • CSC 711 Answers (OS-Q1a ... OS-Q6b)
  • CSC 715 Answers (SE-L1Q1 ... SE-L10Q5)
  • CSC 718 Answers (IS-Q1a ... IS-Q8c)

4. Study chatbot

Open the Chatbot (raw PHP + Groq)

The chatbot gives short, exam-ready answers at MSc level. It keeps your conversation history, lets you browse and continue old chats, and jumps around long answers with the history index.
