Question 2 | Neuro-Fuzzy, Genetic Programming and ANN

Scenario: A class of 400 postgraduate AI students, grouped into 40 work teams, must each build a ChatBOT trained to correctly vocalise English homonyms: ONE, WARN, WON, WORN, NOT, NUT, NAUGHT and NORTH. The goal is to select one BOT with the best performance (above 90% success), using an ANN for training and another AI system to critique and evaluate each candidate BOT.

a) Most appropriate ANN type for the training, and why

A Recurrent Neural Network (RNN), preferably an LSTM (Long Short-Term Memory) or GRU variant, is the most appropriate. A Multilayer Perceptron (MLP) trained with back-propagation is the suitable simpler alternative when fixed-length feature vectors are used.

Why the RNN / LSTM:

  • Speech is sequential / temporal data. A spoken word is a time-series of phonemes; an RNN has internal "memory" (hidden state) so it can use the order and context of sounds, which is exactly what distinguishes homonyms such as WON from ONE or NOT from NAUGHT.
  • Variable-length input. Words are not all the same length; RNNs naturally handle variable-length audio frames, unlike a plain MLP that needs a fixed-size input.
  • Temporal dependencies. LSTM/GRU gates solve the vanishing-gradient problem of simple RNNs, so they capture long-range dependencies in the audio signal, giving higher recognition accuracy.
  • Output layer. A softmax output layer with one node per target word class gives the probability of each homonym, and the highest-probability word is the BOT's answer.

Memory Aid: Speech = sequence -> use a network with memory -> RNN / LSTM. If only static features are available, use an MLP with back-propagation.

b) Which AI system should evaluate the BOTs?

A second, independent ANN - a feed-forward (MLP) classifier trained on ground-truth pronunciations, acting as an automated "critic" / discriminator. It classifies each BOT's spoken output and compares it with the correct word to compute an accuracy score.

This follows the Generative Adversarial Network (GAN) idea of "AI versus AI": one network generates (the BOT), a second network critiques it. Additional options that can support the critical evaluation:

  • Self-Organizing Map (SOM) - an unsupervised ANN that clusters the produced pronunciations and highlights anomalous / incorrect ones.
  • Fuzzy-logic or expert-system evaluator - applies phonetic rules and fuzzy scores, useful because homonyms differ by subtle acoustic features.
  • Genetic-algorithm fitness evaluator - uses the evaluator's score as the fitness function that drives the evolution of the best BOT.

Exam Tip: The key point is that the evaluator must be independent of the trainee BOT, so that its judgement is unbiased - exactly like a GAN discriminator or an external examiner.

c) Tree or population size for this AI challenge

Population size = 40 - the number of candidate BOTs being evolved (one per work team). In genetic programming each candidate is a program tree, so the population is a pool of 40 trees. The tree size is the number of nodes (functions + terminals) in a single BOT's program representation and is typically variable (bounded by a chosen maximum depth/size) rather than fixed.

  • 400 students is only the total class size (context); the objects competing for selection are the 40 BOTs.
  • Tree size = nodes in each evolved program, e.g. a neural-network structure or rule-set tree. Larger trees can represent more complex BOTs but cost more to evaluate.
