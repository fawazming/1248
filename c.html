PART E - One-Page Cram Sheet

Definitions:

  • Research: organized, systematic way of finding answers to questions; original investigation contributing to knowledge.
  • Problem formulation: one sentence - what problem, to whom/where relevant.
  • Hypothesis: tentative prediction of relationship between variables.
  • Literature review: systematic identification, evaluation & interpretation/synthesis of published work.
  • Thesis: written work from original research for a higher degree.
  • Formal method: logic/maths model evaluated mathematically.

Key lists:

  • Research characteristics: Controlled, Rigorous, Systematic, Valid, Empirical, Critical.
  • Good topic: Interesting, Researchable, Significant, Manageable, Ethical.
  • Objectives: SMART.
  • 4 Ps: People, Problems, Programs, Phenomena.
  • Literature criteria: Relevancy, Objectivity, Reliability, Accuracy, Currency, Legitimacy.

Comparison traps:

  • Validation = spec matches problem; Verification = implementation matches spec.
  • Type I = reject true null; Type II = fail to reject false null.
  • Parametric = normal, interval/ratio; Non-parametric = no normality, nominal/ordinal.
  • Qual = why/how, meaning; Quant = what, numbers.
  • MSc = solve with known methods; PhD = produce something new.

Must-have diagrams:

  • Research process (8 stages, iterative).
  • Methodology workflow (Problem ID -> Design -> Implementation -> Evaluation -> Analysis).
  • Levels of measurement (Nominal -> Ordinal -> Interval -> Ratio).

Five-line essay template (any exam question):1. Define the concept in one sentence. 2. List the components/characteristics. 3. Explain each in one line. 4. Give a research example. 5. Relate it to your own proposed study (FL/DL/XAI for IoMT).

Good luck. Read the boxes twice, reproduce the diagrams once by hand, and answer with keywords.
