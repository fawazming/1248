Fuzzy logic

  • Why fuzzy: real data is imprecise, vague, continuous; Boolean is only 0/1.
  • Tools: linguistic variables, membership functions [0,1], fuzzy IF-THEN rules.
  • 4 stages: Fuzzification -> Inference -> Aggregation -> Defuzzification (F-I-A-D, "Feed In A Decision").
  • Output method: centroid (centre of gravity).
  • Contributions: fuzzy control (washing machines, cameras, ABS, metro); soft computing / neuro-fuzzy (ANFIS).
  • Learning: tune membership functions + rules via ANFIS, GA, or online/incremental learning.

Knowledge engineering

  • KDE joys: accuracy/depth, credibility/validation, rich heuristics.
  • KDE worries: acquisition bottleneck, subjectivity/inconsistency, articulation (tacit knowledge).
  • Neutralise: (1) structured elicitation (interviews, protocol analysis, Delphi, repertory grids); (2) automation + knowledge management (ML/data-mining, versioning, expert review).
  • Common challenge (ES + FL): knowledge-acquisition / representation bottleneck.

ANN, GP and Turing

  • Speech training ANN: RNN / LSTM (sequence memory); MLP for fixed-length features.
  • Evaluator: independent feed-forward ANN critic (GAN idea); SOM, fuzzy/expert, GA fitness also possible.
  • Population size: 40 BOTs (one per team); tree size = nodes per program.
  • GP cycle: Initialise -> Evaluate -> Terminate? -> Selection -> Crossover -> Mutation -> Reproduction -> new generation.
  • Turing Test (1950): Imitation Game; judge texts two hidden respondents; machine passes if indistinguishable. Loebner Prize (1990).

Intelligence and search

  • AI vs Research vs System: field vs activity vs deployed artifact.
  • Gardner five: Word, Number, Space, Music, People.
  • Intelligence activities: learning, reasoning, problem solving, creativity, communication (plus perception/social).
  • Weak vs strong AI: narrow specialised tool vs general self-aware machine (AGI).
  • Search components: I-A-S-G-P (Initial state, Actions, State space, Goal test, Path cost).
  • Search steps: formulate -> represent -> choose strategy -> expand and test -> extract path.
